# Backlog

Ideas that are not in the current session's acceptance criteria. **Nothing here gets built until
it is pulled into a session on purpose.**

This file is what makes "no, not now" survivable. An idea written down with a trigger is not
rejected — it is scheduled.

Format: **idea — why it might matter — what triggers doing it.**

A trigger is a moment that will actually occur ("the first time a colleague needs to run this"),
not a wish ("when there's time").
