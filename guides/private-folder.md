# Your private folder — what no AI can reach

**What it is.** One folder on your laptop that you never give to any AI. The app reads it and shows you
what's in it; an AI can't, because no AI is ever connected to it. It is **not a backup** and not a copy of
anything: it's the one place for details that must stay out of AI sessions.

**What goes in it.** Only what an AI must never see, for example:

- your health details, or anything personal about you beyond how you like to work;
- colleagues' full names, phone numbers or emails, when a project needs them (the project note says
  *see private*);
- anything your company would not want in an AI session.

**Not in it:** your projects, plans, tasks and decisions. Those stay in `projects\`, where the AI helps.

## Set it up — once, about two minutes

1. **Open File Explorer** (Windows key + E).
2. **Go to your user folder:** click the address bar, type `%USERPROFILE%`, press Enter.
3. **Make the folder:** right-click an empty spot → **New → Folder** → name it `private`.
   - Not inside `Documents`, `Desktop` or `OneDrive`: those may be synced to a cloud.
4. **Move your private files in:** open `workspace\projects` in a second window and drag every file
   ending `.local.md` into `private`. Dragging on the same drive moves it.
5. **Tell the app** (once it has the setting): *Settings → Private folder →* choose `private`.

## Using it

- **To read it:** the app shows it next to what it belongs to (your profile, a project's Details), marked
  🔒. Or open the file in any editor.
- **To add something:** in the app, 🔒 ＋ on that section; or open the folder and edit the file.
- **The one rule:** never add this folder to an AI, never start an AI tool inside it, and never start one in
  your whole user folder (`C:\Users\<you>`), because that reaches everything below it, this folder
  included.

## Keep a copy

It's small. Include it in your offline copy (see *Offline copy*), so you don't lose it with the laptop.
