# Asa — read the Instruction for AI, then work

This skill only points; **the knowledge lives in Asa, not here**. That way it's the same for every
account and every AI tool, and Nico can read it in Asa (Instruction for AI).

1. **Open `projects\AGENTS.md`, Asa's Instruction for AI,** (the folder above the project you're working in) **and follow it.**
   It's the whole instruction: the loop, what to read for which job, how things link, and the exact
   shape of every file you write.
2. **If you can't find it,** read the project's `HOW-ASA-WORKS.md`, which points to the same manual.
3. **If neither exists,** tell Nico that Asa's Instruction for AI is missing, before doing anything else.
